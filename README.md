# LabirintAI — агент обучения с подкреплением в лабиринте

Простой учебный проект по **обучению с подкреплением (Reinforcement Learning)**: агент учится находить выход из лабиринта с помощью Q-обучения (Q-learning). Подходит для демонстрации в университете: можно показать, как агент сначала блуждает наугад, а потом постепенно выучивает оптимальные маршруты.

## Что внутри
- `src/` — исходники (логика лабиринта, агент, запуск/визуализация).
- `pyproject.toml` — зависимости и метаданные проекта.
- `Taskfile.yml` — команды для `go-task` (если пользуешься).
- `.python-version` — версия Python (см. файл).
- `uv.lock` — lock-файл менеджера пакетов `uv`.

## Установка

> Требуется **Python 3.x** (см. `.python-version`). Рекомендуется 3.11+.

Есть несколько вариантов — выбери удобный.

### Вариант A: через `uv` (быстро и просто)
```bash
# 1) Установка uv (если нет)
# Linux/Mac:
curl -LsSf https://astral.sh/uv/install.sh | sh

# 2) Установка зависимостей
uv sync

# 3) Активация среды (опционально)
source .venv/bin/activate
```

### Вариант B: стандартный venv + pip

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -U pip
# Если зависимости описаны в pyproject.toml — поставь:
pip install .
# или если есть requirements.txt — поставь:
# pip install -r requirements.txt
```

### Вариант C: через `poetry` (если удобнее)

```bash
poetry install
poetry shell
```

## Запуск

Минимальный запуск (замени путь на свой, если у тебя другой entrypoint):

```bash
# Вариант 1
python src/main.py
```

Если предусмотрены параметры (эпизоды, визуализация и т.п.), можно добавить, например:

```bash
python src/main.py --episodes 500 --render 1
```

> Если параметров нет — просто запускай без флагов.

## Идея алгоритма (в двух словах)

* Агент получает **награду** за достижение цели (выход из лабиринта) и, возможно, небольшие штрафы за шаги/удары в стену.
* В таблице **Q-значений** хранится «насколько хорошо сделать действие *a* в состоянии *s*».
* На старте агент **исследует** (ходит наугад), потом всё больше **использует** накопленные знания.
* Со временем путь становится короче и стабильнее.

## Как показать в универе

1. Запусти обучение на простом лабиринте, включи визуализацию.
2. Покажи, как агент сначала блуждает, а затем уверенно идёт к выходу.
3. Сравни длину пути/кол-во шагов в начале и в конце обучения.
4. Коротко объясни: «Награда → Q-таблица → баланс исследовать/использовать».
